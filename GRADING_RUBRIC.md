# A2 Grading Rubric

- **Custom linked list: 10 points** — Correct memory management, search/traversal, insert/remove behavior.
- **Custom circular queue: 10 points** — FIFO correctness, wrap-around, growth, empty-state handling.
- **Custom hash table: 16 points** — Separate chaining, insert/find/erase, collision handling, load factor, rehash.
- **Data loading and repository: 10 points** — Loads/validates all files and constructs consistent in-memory data.
- **Registration and prerequisite logic: 14 points** — All validation rules, capacity logic, duplicate prevention, clear reasons.
- **Drop, waitlist, and automatic promotion: 12 points** — Correct removal and FIFO promotion without exceeding capacity.
- **Undo stack behavior: 8 points** — Correct LIFO reversal and no recursive undo-record bug.
- **Queries, saving, and UI robustness: 8 points** — Schedules/rosters/waitlists, persistence, usable menu, safe input.
- **Design/performance report: 8 points** — Architecture, complexity, hash analysis, edge cases, references.
- **Code quality: 4 points** — Readable organization, meaningful names, reasonable documentation.
