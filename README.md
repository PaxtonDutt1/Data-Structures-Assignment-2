# Assignment 2 - University Registration & Waitlist System

## Included

- `A2_Specification.docx` - complete requirements and grading rubric
- `src/` - starter C++ files
- `data/` - synthetic input datasets
- `reports/` - location for the required design/performance report
- `CMakeLists.txt` - CMake build configuration

## Build

```bash
mkdir build
cd build
cmake ..
cmake --build .
```

Run the executable with the data-directory path if necessary:

```bash
./a2 ../data
```

On Windows the executable may be `a2.exe`.

## Important

The starter code is intentionally incomplete. Students must implement the linked list, queue, hash table, registration rules, waitlists, undo behavior, file processing, reporting, and application integration.

Do not replace the required custom linked list, queue, or hash table with STL containers unless the specification explicitly permits an STL container for a non-required supporting role.
