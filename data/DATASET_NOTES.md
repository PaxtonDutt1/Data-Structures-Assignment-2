# Dataset Notes

The assignment includes the following synthetic input files:

- `students.csv` - 1,500 student records
- `courses.csv` - 80 course-section records
- `prerequisites.csv` - 60 prerequisite relationships
- `completed_courses.csv` - 12,076 completed-course records
- `initial_registrations.csv` - 2,222 existing registrations
- `sample_commands.csv` - small command examples for manual testing

These files are synthetic and are intended only for this programming assignment.

The starter application should load the files at runtime. Do not hard-code the dataset contents into the program.
